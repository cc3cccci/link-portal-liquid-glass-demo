# Link Portal · Liquid Glass Demo

Pure CSS demo of the **工作 (Work)** page using Apple Liquid Glass style.

## Live Demo

**Open the live preview:**  
https://htmlpreview.github.io/?https://github.com/cc3cccci/link-portal-liquid-glass-demo/blob/main/index.html

Or download `index.html` and open it directly in any browser.

## Features

- Real `backdrop-filter` frosted glass
- Top specular highlight (inset white shadow)
- Soft multi-layer shadows
- Category color left accents + soft wash
- Hover lift effect
- Works over any wallpaper (Bing-style background included)
- Fully responsive

## How to use in your project

1. Copy the CSS variables and `.glass` / `.card` styles from `index.html`
2. Apply `class="glass card"` and `data-cat="work|network|repo|ai|academic|cloud"`
3. Make sure the parent has a background image/color so the glass can blur it
